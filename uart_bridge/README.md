# uart_bridge
Originally at https://github.com/adityaagrawal53/uart_bridge
`DPP_echo_AP` contains the code flashed onto the AP side of the DPP for serial port echo capabilities
`ros2_ws` contains the scripts used for `/amcl_pose` generation (`amcl_pose_generator`) and the metrics generator (`metrics_sliding`)
`scripts` contains miscelleanous scripts helpful for automation, testing and debugging.
